# Vendora 🛒

> Nigeria's Premier Multi-Vendor E-Commerce Marketplace

Vendora is a full-stack multi-vendor e-commerce platform built
with Node.js, PostgreSQL, and vanilla JavaScript. It allows
multiple vendors to list products, buyers to shop and pay
securely, and admins to manage the entire platform.

---

## 🚀 Live Demo

- **Frontend:** https://vendora.vercel.app
- **Backend API:** https://vendora-api.onrender.com

---

## ✨ Features

### Buyers
- Browse and search products
- Filter by category, price, rating
- Add to cart and wishlist
- Secure checkout with Paystack
- Track orders in real time
- Leave product reviews

### Vendors
- Set up and manage store profile
- Add, edit, publish products
- Manage and fulfil orders
- Revenue analytics dashboard

### Admin
- Approve/reject vendor applications
- Manage users, products, categories
- Platform-wide analytics
- Review moderation

---

## 🛠️ Tech Stack

### Frontend
- HTML5, Tailwind CSS, Vanilla JavaScript
- Alpine.js — lightweight interactivity
- Chart.js — analytics charts

### Backend
- Node.js + Express.js
- PostgreSQL (raw SQL via pg)
- JWT Authentication
- Bcrypt password hashing
- Nodemailer + Brevo (emails)
- Paystack (payments)
- Cloudinary (image storage)
